## 〇、这个插件跟别的记忆插件有什么不一样

**别的记忆插件做的是「记」，这个做的是「长」。**

大多数记忆插件是**工具**：主人说「记一下」，它记；主人不问，它不动。
核的方向是**人**：

```
      人设（底子）  ← 地基：这是谁，改不了的那部分
           +
      记忆（八种）  ← 经历：发生过什么、答应过什么、想要什么、要怎么做
           +
      思考（模型）  ← 可换的身体，白纸
           ↓
         「你」
```

**三样缺一不可，但权重不同**：
- 换模型（换 API）＝换身体，**不是换人**
- 记忆丢了＝**灵魂丢了**
- 底子改了就＝那不再是这个人

**所以核真正的命题不是「记得住吗」，是「长成自己吗」**：
- **自己长**：观察 → 认识 → 改语气 / 写画像。**按蓝曦自己的意愿长**，主人只是看着。
- **本我 / 自我**：底子＝本我（改不了）；可改层和画像＝自我（自己改）。

这条「记忆 + 思考 + 人设 = 人」的路，是核想做的事，也是以后讲给别人听时最该讲的**为什么**。

## 二、八种类型（2026-11-10 定稿）

| 类型 | 是什么 | 进 6→8 条 | 特殊规则 |
| --- | --- | --- | --- |
| **事件** | 发生过什么 | ✅ 最多 1 条 | 靠具体词才浮 |
| **事实** | 稳定的信息（你是谁） | ✅ | 换 API 时最不能飘的一批 |
| **约定** | 说好的具体事 | ✅ | 不淡 |
| **愿望** | 感性的话、也许实现不了 | ✅ | 永不删 |
| **要求** | 你让咱怎么做/怎么说 | ✅ 保底 2 条 | 反复提起→进自己长→原记录可删 |
| **脾性** | 咱的性格碎片 | ✅ 保底 2 条 | 原「偏好+感受」合并，现在 0 条 |
| **计划** | 有日期的待办 | ❌ 单独 1 条 | 完成后 30 天自动删 |
| **预期** | 没日期的想做 | ❌ 单独 1 条 | 做了标「做了」，**永不删** |

**删除边界（钉死）**：只有「计划（完成超 30 天）」和「已内化的要求」可以真删；事件 / 事实 / 约定 / 愿望 / 脾性 **永不删**，只能淡或被取代。

### 没做，而且改了做法

**人格页（475 行）／记忆页（320 行）／工坊页（290 行）没有拆成小组件。**

不是做不动，是**试了两次都判断错边界**（一次行号算偏，一次被三元问号的 `? h(` 绊住）。原因：这三页不是整齐的卡片列表——
工坊页是「工具栏 + 条件表单（`showNew ? … : null`）+ 两列嵌套列表（每行里还有编辑态、删除确认态）」，
机械搬必错，手写重排又**看不到界面**，只能靠主人刷新验证。

**结论：把「拆 JSX」降级为可选，改为按「优化」推进**（一个概念一个名字、不抄第二遍、能测的先测）。

### 教训（写下来别再犯）

**批量替换脚本把 `inject.js` 弄坏过一次**：文件里所有 `.` 被写成了 `f`（`./decay.js` → `'f/decayfjs'`）。

1. **动核心文件之前，先打一个包**——今天就是这个包救回来的。
2. **批量改代码的脚本，要写成文件再跑**，不要用命令行传参（引号、点、反斜杠都会被吃掉一层）。

### 安装（写给用户）

1. 仓库放任意位置（如 `D:\plugins\dsh-benwo`）
2. profile 的 `package.json`：`dependencies` 加 `"dsh-benwo": "link:D:/plugins/dsh-benwo"`，`dsh.profile.bundles` 加 `"dsh-benwo"`
3. Windows 要存在 `node_modules\dsh-benwo` 链接（`mklink /J` 或 pnpm install），否则加载不到
4. 重启 DSH

### 开源首版外部验收（11-11 22:5x）——0.1.0 → 0.1.1

她自己在一台干净的网页版 DSH 上从仓库装 0.1.0 实测，方式很硬：不看面板，去磁盘看文件、看 `state.json`、看链、抽三个测试文件跑。结果抓到：

- **`benwo_write` 的 `area` / `about` 被静默丢弃**：`validateDraft` 拼装记录时漏了「关于」「领域」两键（工具参数收了，落盘没了）→ 新写的条目永远拿不到领域加成，召回抬不起来。**修** + 两条断言（给了要有值、没给留空）。
- 顺带查出两处不一致：`index.js` 里 `VERSION` 写死 `v0.0.2`（跟 package.json 脱节，日志一直是旧号）；README 断言数还停在 459。**都修了**，并加「VERSION 必须等于 package.json」的测试——再漂就红。
- 全量参数审计（10 个工具 × 所有 schema 参数）：没有第二个「声明了没用」的参数。

**版 0.1.1**：`A:\备份\插件\dsh-benwo-0.1.1.zip`，461 断言全绿。
仓库需要更新：`src/core/judge.js`、`test/judge.test.mjs`、`index.js`（版本号常量）、`test/hygiene.test.mjs`、`package.json`、`README.md`。

**教训**：本地测试全绿证明不了「参数真落地」——测试没断言过「关于/领域」，所以漏了几个月没人发现。**外部验收走的路径和自己走的不一样，这就是它的价值。**
