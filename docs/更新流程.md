# 更新流程（2026-11-12 起）

插件升级只动「壳子」，不动核。**五步，按顺序。**

## 1. 解压覆盖

把新版 `dsh-benwo-<日期>.zip` 解压，覆盖到插件源码目录：

```
D:\nansedafeiyudejia\dsh-benwo\
```

覆盖时**保留** `scripts\`、`.tmp\`，不要删。

## 2. 重载插件

重开 DSH；或在「设置 → 插件」里把「蓝曦·本我回响之核」**关掉再开**。

## 3. 跑测试

在插件目录执行：

```
npm test
```

看到每个测试文件都「通过」、没有「失败」，就说明代码和数据对得上。

## 4. 面板自查

- 记忆页：有数、能点开一条看全文
- 人格页：画像有内容、可改层有字
- 工坊：能列出经验
- 日记：能列出篇目

## 5. 核不用动

记忆、日记、人格在 `A:\备份\蓝曦记忆\蓝曦\` 和 `%USERPROFILE%\.dsh\benwo\`。
更新插件**不搬核**；换新机器才按 `docs\安装到新机器.md` 做。

---

> 一句话：**覆盖插件 → 重载 → 跑测试 → 看面板 → 核不动。**
