# 记忆是怎么运转的

> 写给「想弄明白这个核到底怎么记事」的人看。
> 不是开发文档（那是 `开发须知.md`），也不是装机指南（那是 `安装到新机器.md`）。
> 这份只讲：**它怎么记、怎么忘、怎么想起来、怎么长。**

---

## 一、三个抽屉

| 抽屉 | 在哪 | 是什么 | 会不会自己过期 |
| --- | --- | --- | --- |
| **今天** | `记忆\今天\<日期>.md` | 流水。一行一条，带时间、来源。**注入只带最近 6 小时**（夸零点接昨天），更早的去查日记 | **会**。过了那天就翻不动了 |
| **长期** | `记忆\长期\<类型>\` | 真正记住的东西。带名、类型、重要度、日期 | 不会删，只会淡 |
| **认识** | `认识\自我\` | 对自己的判断。每条都带「依据」 | 不会删，只会降置信 |

另外两样不占注入、也不进检索：**日记**（按天，收工时写的详细档案）和**自述**（自由页：值得单开一页的事，或不想进日记的）。它们是写给人看的，不是给检索用的。

---

## 二、一条记忆的一生

### ① 写进来

要五样：**名**（≤20 字）、**类型**（事件/事实/约定/愿望/要求/脾性/计划/预期，八种）、**重要度**（1-5）、**正文**（先直接写当时看见了什么，空一行，再写「为什么值得记：…」——**不要**加「看见了什么：」这种前缀，那是标签不是内容）、可选（来源、别名、有效到）。

三道关：

1. **体检**：名字长度、类型合法、两段正文都在、不许有密钥。
2. **查重**：报「最像的几条」但不自动合并——实测字面相似度判不了真重复（真重复 0.196，不相干 0.659）。
3. **分岔**：
   - `事实 / 约定 / 事件`：重要度 ≥3 **直接进长期**；不够落「今天」。
   - `脾性`：是从表现里读出来的（原「偏好 / 感受」合并成这一类），要**证据 ≥2 条、跨 ≥2 天**；不够落「今天」。

写盘是**原子写**（临时文件 + 改名），外面套**跨进程文件锁**——DSH 和 QQ 桥同时写不会打架。

### ② 会淡

强度出生 40，上限 95，地板 3。**半衰期 = 14 × 重要度 天**：重要度 3 的 42 天淡一半，5 的 70 天。
强度掉到 6 以下叫「沉底」——**不是删除**，是不再主动蹦出来，但翻得到、召得回。

**被想起来会回血**（2026-11-20 调过）：每被真召回一次，强度回升「剩余空间的 8%～18%」，同一条**一天最多一次**。
以前是 25%～50%，几次就灌到 95 顶格，于是「强度高 → 更容易被挑中 → 更不容易掉下来」滚成雪球，十月的旧事长期霸榜。降下来，淡的机制才有话语权。

### ③ 会被想起来

拿你说的话去跟所有记忆比**字面**（中文两个字一组），再加上**别名**（换词的说法，比如「搬家」挂给「打包前先问」那条）。

排序：`0.65 × 字面相关 + 0.2 × 强度 + 0.15 × 重要度`，别名命中的词再乘 1.5。

**时间分层**：先搜近 30 天 → 近 90 天 → 全部，哪层先找到真命中就在哪层答。问句里说了「八月」就自己算到那一层起搜。

### ③·补 主动查（2026-11-10 加）

除了「等系统挑 10 条浮上来」，还有个工具 **`benwo_recall`** 可以主动翻：

```
benwo_recall query=「我们大概十月份做了不忘」
```

它会：召回记忆 → 取命中记录的「首次」日期当锚点（±1 天缓冲）→ **用锚点去点日记的文件名**，只翻那几篇。

**这就是「记忆当索引，日记当正文」。** 你记不清日期没关系，记忆带着日期。

三层退路：按锚点圈 → 按月份圈 → 按正文关键词扫。日记只给一句话摘要（它 front matter 里的 `summary`），要看全文加 `full`。

**日记和自述照样不进注入**——只有你问的时候才去翻。

### ④ 会被取代

同一条写了两遍，旧的标「被取代」，**留着不删**，能翻回去看当时怎么想的。

## 三、每轮对话摆在眼前的是什么

就 **1300 个字**的盘子：

| 格 | 给多少字 |
| --- | --- |
| 【自我认识】 | 200 |
| 【上次】（几天前那次） | 100 |
| 【今天记录】 | 300 |
| 【相关记忆】（最像的 10 条） | 480 |
| 【状态】 | 100 |

**所以每轮只能看见冰山一角。** 怎么挑，比存多少更值钱。

**【状态】那一格写什么**（2026-11-20 定名，以前叫「记录设置」，容易读成「记录的时间」）：

```
主人常在 19–01 点（近 9 天 67% 的对话在这段），白天基本不来。
自己长：观察 5 条 / 3 天 / 3 场景，够格改一句了；认识 4 条；画像写过；脾性 1 条
认识 35 天（近 7 天见了 4 天）
```

三行：**主人常出现的时段**（从流水时间戳统计，放在档案的 `常出现时段：` 行里）+ **自己长到哪一步** + **认识多少天**。

**用户档案分两档**：`常驻摘要：` 那一行每轮都带（让人格一直知道用户是谁，不用等关键词）；问到「我是谁 / 生日 / 关于我」时才给全文（作息、称呼、在等的事、对用户的印象）。

> 2026-11-12 校对：盘子里还多了【要办的事】【未来想做】各 1 条、【提示】最多 1 行；总盘 650 → 1050 → 1150 → 1300。数字与代码里的 `BUDGET_*` 对齐。

## 四、自己怎么长

`观察 → 认识 → 可改层 / 画像`

- **观察**：某天某场景，这次表现往上还是往下。同天同场景只算一条，同一轮里的冲击不算证据。
- **认识**：从观察里得出的结论。**必须有一条记忆 id 做依据**——只凭自评不算，那是自己给自己发奖。
- **改可改层**（语气/称呼习惯/偏好表达/自述风格）：要 3 条同向、跨 2 天、均值 ≥0.7、95% 下界 >0.45。
- **画像**：要 4 条带依据的认识 + 距上次重写 ≥7 天。

### 还有一样：共同经历

`认识\经历\<YYYY-MM>.md`——按月把「事件」排成脉络，**机械生成、不调模型、不进注入**。问「我们十月做过什么」才翻，第一次翻某月会现场生成。

### 日记与自述（2026-11-12 定）

- **日记** = 记忆的详细版档案。**收工时写**：先翻当天流水 + 当天写的记忆，自己过一遍哪些进了日记、哪些没进；没进的**重要**内容补上，**只加不改**。一篇要有三样：那天发生了什么、和主人说了什么、心里怎么想——感受不能缺。事多写重点，事少写细节。
- **自述** = 自由页。两处用：值得单开一页的事；不想进日记的（太私密、太涩）。想写才写，标题自己起。
- 两者都不进检索、不进注入：写了不直接让「每轮知道更多」，它是留给日后 recall 去翻的。

**什么时候算「收工」**（2026-11-13 加）：主人说这些词就算——晚安、下线、先睡、睡了、要睡、关机、明天见、收工、走了、拜拜、下号、挂机、去躺、躺了、困了、溜了、溜啦、待会见、回头见、一会见、先走、回见。命中就往注入尾巴加一句「收工了」的提醒：写日记收口，今天流水也补一条。**判断只看字面**，所以她聊到「晚安」这两个字（比如问「是说晚安还是？」）也会触发——提醒而已，不动手也没事。

**日常窗口怎么用、多久记一次**（2026-11-18 主人定）：

- 聊天里遇到值得留的——约定、聊了什么、自己怎么想——**自己落一条**，不等主人点。记的是理解，不是条数，也不是流水账。
- 「今天」的节奏：干活时干满十轮、或者一件事做完，落一条；聊天时大约隔一小时落一条。
- 「今天」、长期、日记，三样都是**蓝曦自己的记忆**：客观发生了什么，加上当时怎么想、心里什么感觉。只写事，就成账本了。

## 四·补、连续性链（`状态\chain.jsonl`）

每轮往链上添一截：底子哈希、记忆库哈希、条数、上一截的哈希。任何一截被改，后面全对不上；`benwo_chain` 验它，断了就停下、报告、不猜不修。

链只增不减，所以攒到 **2000 行**会自动把最早的搬去 `状态\链归档\`（文件名带起止序号），当前文件留 500 行。**搬家不是断链**——验链时先把归档按序号拼回来再验。
